API e exemplos

Como funciona

Cada extensão é uma pasta com um manifest.json. Ela pode ter scripts de conteúdo (rodam nos sites que você escolher), um botão com pop-up na barra, um script de clique e até substituir a nova aba.

{
  "name": "Minha extensão",
  "version": "1.0",
  "icon": "icon.svg",
  "content_scripts": [{
    "matches": ["youtube.com", "*://*.google.com/*", "<all_urls>"],
    "js": ["content.js"],
    "css": ["style.css"],
    "run_at": "document_idle",
    "world": "MAIN"
  }],
  "action": { "default_popup": "popup.html", "default_title": "Minha extensão" },
  "newtab": "newtab.html",
  "options_page": "options.html"
}

Campos do manifest

content_scripts[].matches<all_urls> (todos os sites e a nova aba), youtube.com (o site e subdomínios), *://*.site.com/caminho/*, newtab ou *.
exclude_matchesEndereços em que o script não deve rodar.
run_atdocument_start (antes da página), document_end (DOM pronto) ou document_idle (padrão).
worldMAIN: roda junto com o JavaScript do site (acessa as variáveis dele). ISOLATED (padrão): mundo separado, com a API tuff.
all_framestrue para rodar também dentro de iframes.
action.default_popupPágina HTML que abre ao clicar no botão da extensão.
action.runArquivo .js executado na aba aberta a cada clique (sem pop-up).
newtabPágina HTML que vira a sua nova aba.
incognitotrue para rodar também nas janelas anônimas.

API tuff

Disponível no pop-up, na nova aba, nas opções e em scripts ISOLATED (os marcados com • só nas páginas da extensão).

await tuff.storage.get(chave)Lê um valor salvo (sem chave: tudo). Também set(chave, valor), remove, clear e onChanged(fn).
tuff.notify(texto)Mostra um aviso rápido no navegador.
await tuff.fetch(url, opções)Busca qualquer endereço sem bloqueio de CORS. Retorna { ok, status, headers, text }. Use { as: 'dataurl' } para imagens.
tuff.tabs.create({ url })Abre uma aba nova.
• await tuff.tabs.active()Título e endereço da aba aberta.
• await tuff.tabs.execute(código)Roda JavaScript na aba aberta e devolve o resultado.
• tuff.tabs.update({ url })Navega a aba aberta.
• tuff.browser.search(texto)Pesquisa com o buscador escolhido (na aba atual).
await tuff.browser.engine()Buscador atual. • engines() lista todos e setEngine(id) troca.
• await tuff.browser.topSites()Sites mais visitados. Também bookmarks() e theme().
• tuff.action.setBadge(texto, cor)Mostra um número no botão da extensão.
• tuff.popup.close()Fecha o pop-up.
tuff.runtime.openOptions()Abre a página de opções.
tuff.getURL(arquivo)Endereço de um arquivo da extensão (tuff-ext://id/arquivo).
